## 1. Призначення та важливі попередження

Цей README описує повний процес: від створення інсталяційної флешки до перевірки готового комп’ютера.

Для налаштування аудіо- та відеосистеми враховано матеріали:

- **S-132-K**: вказівки щодо налаштування комп’ютера аудіо- та відеосистеми Залу Царства.
- **S-144-K**: вказівки щодо відтворення медіафайлів під час зібрань.

Обидва документи містять інструкції для попередніх версій Windows, тому назви пунктів меню у Windows 11 можуть відрізнятися. Нижче наведено послідовність для Windows 11 із поясненнями призначення основних налаштувань.

### Важливо перед початком

- **Встановлення з видаленням розділів диска знищує дані на них.** Переконайтеся, що потрібні файли збережено в іншому місці.
- Не вимикайте комп’ютер кнопкою живлення під час встановлення або оновлення Windows.
- Не від’єднуйте інсталяційну флешку, доки інсталятор не завершить копіювання файлів і не перейде до перезапуску.
- Не встановлюйте невідомі драйвери, активатори Windows або сторонні «збірки» операційної системи.

## 2. Що знадобиться

Перед початком підготуйте:

| Що потрібно | Для чого |
|---|---|
| USB-флешка від 8 ГБ | Для інсталятора Windows |
| Інший робочий комп’ютер | Для створення інсталяційної флешки, якщо потрібно |
| Підключення до Інтернету | Для оновлень і драйверів |
| Клавіатура, миша та монітор | Для керування комп’ютером |
| Резервна копія потрібних файлів | Для захисту даних |
| Дані про обладнання та підключення | Для правильного налаштування дисплеїв і звуку |

## 3. Підготовка інсталяційної флешки

### Крок 1. Завантажте Windows 11

1. Відкрийте офіційну сторінку завантаження Microsoft:  
   https://www.microsoft.com/software-download/windows11
2. Знайдіть розділ створення інсталяційного носія Windows 11.
3. Завантажте офіційний засіб створення носія.
4. Запустіть завантажений файл.
5. Підтвердьте запит контролю облікових записів, якщо він з’явиться.

Не завантажуйте інсталятор із випадкових сайтів. Економія кількох хвилин не варта ризику отримати змінений образ системи.

### Крок 2. Створіть флешку

1. Підключіть USB-флешку до іншого комп’ютера.
2. Переконайтеся, що на ній немає потрібних файлів.
3. У засобі Microsoft виберіть створення інсталяційного носія.
4. Виберіть потрібну мову та випуск Windows.
5. Виберіть USB-накопичувач.
6. Укажіть саме свою флешку.
7. Дочекайтеся завершення завантаження та створення носія.

**Увага:** під час створення інсталятора флешка буде відформатована. Усі дані на ній буде видалено.

Коли засіб повідомить про завершення, безпечно витягніть флешку.

## 4. Підготовка комп’ютера

Перед установленням:

1. Переконайтеся, що потрібні файли скопійовано в безпечне місце.
2. Вимкніть комп’ютер штатним способом.
3. Підключіть клавіатуру, мишу та основний монітор.
4. Підключіть мережевий кабель, якщо він використовується.
5. Від’єднайте непотрібні зовнішні накопичувачі, щоб випадково не вибрати їх для встановлення.
6. Підключіть інсталяційну флешку до USB-порту комп’ютера.

## 5. Запуск комп’ютера з флешки

1. Увімкніть комп’ютер.
2. Одразу після ввімкнення кілька разів натисніть клавішу меню завантаження `Esc` або `F2`
3. Якщо меню не з’явилося, перезапустіть комп’ютер і спробуйте іншу клавішу, зазначену виробником.
4. У меню виберіть USB-флешку. Якщо є два варіанти, вибирайте варіант із позначенням `UEFI`.
5. Дочекайтеся запуску інсталятора Windows.

**Не змінюйте наугад налаштування BIOS/UEFI.** Якщо флешка не відображається, спочатку перевірте її на іншому комп’ютері та переконайтеся, що носій створено правильно.

## 6. Встановлення Windows 11

Після запуску інсталятора:

1. Виберіть українську мову встановлення.
2. Виберіть формат часу UTC+2.
3. Виберіть розкладку клавіатури.
4. Натисніть кнопку продовження встановлення.
5. Якщо з’явиться запит на введення ключа продукту, виберіть варіант пропуску.
6. Виберіть редакцію Windows Home.
7. Прийміть умови ліцензії.

Коли інсталятор запитає тип встановлення, виберіть **вибіркове встановлення** для чистого встановлення Windows.

## 7. Вибір диска та копіювання файлів

Цей етап потребує особливої уваги.

### Як вибрати диск

На екрані відобразяться накопичувачі та їхні розділи.

1. Знайдіть накопичувач, на який потрібно встановити Windows.
2. Перевірте його місткість, щоб не переплутати з іншим диском.
3. Якщо на диску є потрібні файли, зупиніться та перевірте резервну копію.
4. Для чистого встановлення на спеціально підготовлений диск можна видалити його старі системні розділи, якщо точно визначено правильний накопичувач.
5. Виберіть незайнятий простір на цільовому диску.
6. Натисніть кнопку продовження встановлення.

**Не видаляйте розділи, якщо не впевнені, якому диску вони належать.** Якщо в комп’ютері кілька накопичувачів або незрозуміло, де зберігаються дані, краще зупинитися й попросити допомоги.

### Копіювання файлів

Після вибору диска Windows почне копіювати та готувати файли.

- Дочекайтеся завершення процесу.
- Комп’ютер може перезавантажуватися кілька разів.
- Не вимикайте живлення.
- Якщо після перезавантаження інсталятор знову починається з першого екрана, не запускайте встановлення повторно. Витягніть флешку після завершення першого етапу або виберіть внутрішній накопичувач у меню завантаження.

## 8. Початкове налаштування Windows

Після встановлення Windows відкриється початкове налаштування

1. Виберіть країну "Україна".
2. Виберіть основну розкладку клавіатури - "українська".
3. Додайте російську та англійську розкладку.
4. Підключіться до мережі.
5. Виконайте інструкції на екрані щодо облікового запису.
6. Налаштуйте параметри конфіденційності відповідно до бланку S-132.
7. Дочекайтеся підготовки робочого столу.

## 9. Створення облікових записів

Для комп’ютера аудіо та відеосистеми передбачені локальні облікові записи. Спитайте відповідального брата, щоб отримати більше інформації.

### Створення локального облікового запису

1. Відкрийте **Параметри**.
2. Перейдіть до **Облікові записи**.
3. Відкрийте розділ інших користувачів або користувачів пристрою. Назва може відрізнятися залежно від версії Windows.
4. Виберіть додавання облікового запису.
5. Виконайте запропоновані кроки для створення локального користувача.

## 10. Активація Windows

Зазвичай Windows 11 автоматично визначає ліцензійний ключ, збережений у прошивці материнської плати, і активується після підключення до Інтернету. Якщо цього не сталося, виконайте такі дії:

1. Відкрийте Параметри → Система → Активація.
2. Перевірте стан активації Windows.
3. Якщо Windows не активовано, натисніть **Усунення несправностей**, якщо ця кнопка доступна.
4. Якщо Windows не активовано, перевірте підключення до Інтернету та відповідність установленої редакції вашій ліцензії.
5. Якщо активація не вдалася, зверніться до відповідального брата.

Важливо: не вводьте випадкові ключі активації та не використовуйте сторонні програми актіватори або сервіси для активації Windows.

## 11. Драйвери та оновлення обладнання

Після встановлення Windows 11 необхідно перевірити драйвери та встановити програмне забезпечення для основних компонентів комп’ютера й аудіо- та відеосистеми.
#### 1. Перевірка драйверів через Windows Update

Спочатку встановіть оновлення, які пропонує Windows.

1. Відкрийте **Пуск → Параметри**.
2. Перейдіть до розділу **Windows Update**.
3. Натисніть **Перевірити наявність оновлень**.
4. Дочекайтеся завершення перевірки та встановіть доступні оновлення.
5. Якщо в розділі **Додаткові параметри → Необов’язкові оновлення** є оновлення драйверів, перевірте їхній вміст. Встановлюйте відповідні драйвери для обладнання цього комп’ютера.
6. Якщо Windows запропонує перезавантаження, збережіть відкриті файли та перезавантажте комп’ютер.
7. Після перезавантаження знову перевірте наявність оновлень. За потреби повторіть процедуру.

Докладніше: [офіційна інструкція Microsoft щодо оновлення драйверів](https://support.microsoft.com/en-gb/windows/update-drivers-through-device-manager-in-windows-ec62f46c-ff14-c91d-eead-d7126dc1f7b6).

#### 2. Драйвер відеокарти NVIDIA

Для відеокарти NVIDIA використовуйте офіційну програму **NVIDIA App**. Вона допомагає легко і безпечно отримувати оновлення драйверів і керувати налаштуваннями відеокарти.

**Офіційне завантаження:** [NVIDIA App](https://www.nvidia.com/en-us/software/nvidia-app/).

Порядок дій:

1. Відкрийте посилання вище.
2. Завантажте [NVIDIA App](https://www.nvidia.com/en-us/software/nvidia-app/) з офіційного сайту NVIDIA.
3. Запустіть завантажений файл і виконайте інструкції встановлення.
4. Якщо Windows запитає дозволу на внесення змін до комп’ютера, перевірте назву програми та підтвердьте запуск офіційного інсталятора.
5. Відкрийте [NVIDIA App](https://www.nvidia.com/en-us/software/nvidia-app/).
6. Перейдіть до розділу **Drivers**.
7. Натисніть кнопку перевірки наявності оновлень.
8. Якщо є новий драйвер, завантажте його та встановіть відповідно до інструкцій програми.
9. Якщо після встановлення драйвера буде запропоновано перезавантажити комп’ютер, виконайте перезавантаження.

**Важливо:** для комп’ютера, який використовується для відтворення відео під час зібрань, пріоритетом є стабільність роботи. Не потрібно встановлювати бета-версії драйверів або експериментальні оновлення без необхідності.

Якщо NVIDIA App недоступна або не працює, драйвер можна знайти на [офіційній сторінці завантаження драйверів NVIDIA](https://www.nvidia.com/Download/index.aspx).

#### 3. Драйвери компонентів Intel

Для перевірки сумісних компонентів Intel використовуйте офіційну програму **Intel Driver & Support Assistant (Intel DSA)**.

**Офіційне завантаження:** [Intel Driver & Support Assistant](https://www.intel.com/content/www/us/en/support/detect.html).

Програма перевіряє підтримувані компоненти Intel і показує доступні для них оновлення. Вона не обов’язково знаходить драйвери для кожного пристрою комп’ютера.

Порядок дій:

1. Відкрийте офіційне посилання [Intel Driver & Support Assistant](https://www.intel.com/content/www/us/en/support/detect.html).
2. Завантажте [Intel Driver & Support Assistant](https://www.intel.com/content/www/us/en/support/detect.html).
3. Запустіть інсталятор і виконайте інструкції встановлення.
4. Після завершення встановлення відкрийте [Intel Driver & Support Assistant](https://www.intel.com/content/www/us/en/support/detect.html).
5. Після відкриття сторінки [Intel Driver & Support Assistant](https://www.intel.com/content/www/us/en/support/detect.html) дочекайтеся завершення перевірки. 
6. Якщо браузер покаже запит на дозвіл доступу до локальної мережі (Local Network Access), дозвольте доступ для офіційної сторінки Intel. Це необхідно для зв’язку сторінки з програмою, встановленою на комп’ютері.
7. Якщо з’явиться інший запит, уважно прочитайте його перед підтвердженням. Не дозволяйте доступ невідомим сайтам або програмам.
8. Перегляньте список доступних оновлень.
9. Завантажте та встановіть запропоновані драйвери, які відповідають установленим компонентам Intel.
10. Якщо програма запропонує перезавантаження, виконайте його.

Особливу увагу приділіть драйверам інтегрованої графіки Intel, мережевих адаптерів та інших компонентів Intel, якщо вони встановлені в цьому комп’ютері.

Якщо Intel DSA не знаходить потрібного драйвера, перевірте офіційний сайт виробника комп’ютера або материнської плати.

#### 4. Драйвери Blackmagic Design DeckLink (**лише для облікових записів конгрессу в першому залі**)

Для плати відеозахоплення або відтворення **Blackmagic Design DeckLink** необхідно встановити офіційний пакет **Desktop Video**. Він містить драйвери та програмні компоненти, необхідні для роботи сумісного обладнання Blackmagic Design.

**Офіційне завантаження:** [Blackmagic Design Support Center](https://www.blackmagicdesign.com/support).

Порядок дій:

1. Відкрийте сторінку підтримки [Blackmagic Design Support Center](https://www.blackmagicdesign.com/support).
2. У розділі **Select a Product Family** виберіть **Capture and Playback**.
3. Знайдіть пакет **Desktop Video** у списку доступних завантажень.
4. Переконайтеся, що вибрана версія сумісна з Windows 11 та встановленою моделлю DeckLink.
5. Завантажте інсталятор для Windows з офіційного сайту.
6. Запустіть інсталятор і виконайте інструкції на екрані.
7. Якщо інсталятор попросить перезавантажити комп’ютер, збережіть відкриті файли та перезавантажте систему.
8. Після перезавантаження перевірте, чи розпізнається плата DeckLink та чи працює обладнання з програмами, які використовуються для відтворення відео.

#### 5. Програма для SSD Samsung

Для перевірки стану твердотільних накопичувачів Samsung, перегляду інформації про диск і встановлення доступних оновлень прошивки використовуйте офіційну програму **Samsung Magician**.

**Офіційне завантаження:** [Samsung Magician](https://semiconductor.samsung.com/consumer-storage/magician/).

Порядок дій:

1. Відкрийте офіційне посилання [Samsung Magician](https://semiconductor.samsung.com/consumer-storage/magician/).
2. Завантажте [Samsung Magician](https://semiconductor.samsung.com/consumer-storage/magician/) для Windows.
3. Запустіть інсталятор і виконайте інструкції на екрані.
4. Після встановлення відкрийте [Samsung Magician](https://semiconductor.samsung.com/consumer-storage/magician/).
5. Переконайтеся, що програма розпізнала встановлений SSD Samsung.
6. Перевірте стан накопичувача та доступні оновлення програмного забезпечення.
7. Якщо для накопичувача доступне оновлення прошивки, перед його встановленням створіть резервну копію важливих даних.
8. Виконуйте оновлення лише за потреби та відповідно до інструкцій програми.
9. Не вимикайте комп’ютер під час оновлення прошивки. Якщо програма попросить перезавантажити систему, виконайте цю дію.

**Важливо:** доступні функції залежать від моделі накопичувача. Не всі SSD Samsung, зокрема деякі OEM-моделі, підтримують усі можливості Samsung Magician. Якщо програма не розпізнає накопичувач або не пропонує оновлень, не встановлюйте сторонні драйвери чи прошивки. Спочатку перевірте сумісність моделі на офіційному сайті Samsung.

#### 6. Перевірка диспетчера пристроїв

Після встановлення оновлень перевірте, чи Windows правильно розпізнає обладнання.

1. Клацніть правою кнопкою миші кнопку **Пуск**.
2. Виберіть **Диспетчер пристроїв**.
3. Перегляньте список обладнання.
4. Зверніть увагу на пристрої з жовтим знаком оклику, категорії з невідомими пристроями та повідомлення про помилки.
5. Якщо такі пристрої є, з’ясуйте їхню модель і встановіть відповідний драйвер з офіційного сайту виробника.
6. Після встановлення драйверів перезавантажте комп’ютер, якщо цього вимагає інсталятор.

#### 7. Підсумкова перевірка

Після встановлення драйверів переконайтеся, що:

- Windows не повідомляє про помилки обладнання в Диспетчері пристроїв;
- всі дисплеї працюють належним чином;
- система розпізнає потрібні аудіопристрої;
- плата DeckLink доступна для відповідного програмного забезпечення;
- відтворення відео та звуку працює без помилок.

**Важливо:** не використовуйте сторонні програми для автоматичного оновлення всіх драйверів. Завантажуйте драйвери лише з Windows Update або офіційних сайтів виробників. Не оновлюйте BIOS/UEFI та не змінюйте налаштування прошивки без окремої інструкції відповідального брата.

## 12. Безпека та основні параметри системи

### Захист Windows

Перевірте роботу вбудованого антивірусного захисту та налаштуйте автоматичне сканування на нічний час.

#### 1. Перевірка та налаштування Microsoft Defender

Перевірте стан антивірусного захисту Windows, увімкніть брандмауер і налаштуйте щоденне швидке сканування на нічний час.

**Порядок дій:**

1. Відкрийте меню **Пуск**.
2. Знайдіть **PowerShell**.
3. Клацніть правою кнопкою миші та виберіть **Запуск від імені адміністратора**.
4. Скопіюйте наведені нижче команди, вставте їх у вікно PowerShell і натисніть **Enter**.

**Увімкнення захисту та налаштування розкладу:**

```powershell
Set-MpPreference -DisableRealtimeMonitoring $false

Set-NetFirewallProfile -Profile Domain,Private,Public -Enabled True

Set-MpPreference `
    -ScanScheduleDay Everyday `
    -ScanScheduleQuickScanTime 02:00:00 `
    -ScanScheduleOffset 0 `
    -RandomizeScheduleTaskTimes $false
```

Ці команди вмикають захист Microsoft Defender у реальному часі, вмикають брандмауер для всіх мережевих профілів і налаштовують щоденне швидке сканування на **02:00**.

**Перевірка налаштувань:**

Виконайте такі команди:

```powershell
Get-MpComputerStatus |
    Select-Object AMRunningMode, AntivirusEnabled, RealTimeProtectionEnabled

Get-NetFirewallProfile |
    Select-Object Name, Enabled

Get-MpPreference |
    Select-Object ScanScheduleDay,
                  ScanScheduleQuickScanTime,
                  ScanScheduleOffset,
                  RandomizeScheduleTaskTimes
```

Переконайтеся, що антивірус активний, захист у реальному часі ввімкнений, а для всіх мережевих профілів брандмауера встановлено значення `True`. У розкладі має бути зазначено щоденне сканування на `02:00:00`.

**За потреби ручного сканування:**

Щоб запустити швидке сканування одразу, виконайте:

```powershell
Start-MpScan -ScanType QuickScan
```

**Важливо:**

- Для виконання команд потрібні права адміністратора.
- Час `02:00` визначає запланований початок сканування, але не гарантує його завершення до `05:00`.

### Оновлення Windows

Оновлення Windows потрібно встановлювати **вручну через меню «Пуск»**. Не вимикайте автоматичні механізми безпеки, служби оновлення або системні сповіщення.

1. Відкрийте меню **Пуск**.
2. Виберіть **Параметри → Windows Update**.
3. Натисніть **Перевірити наявність оновлень**.
4. Дочекайтеся завершення перевірки та встановіть доступні оновлення.
5. Якщо Windows вимагає перезавантаження, завершіть роботу відкритих програм і перезавантажте комп’ютер.
6. Перед зібранням не починайте встановлення оновлень, якщо немає достатньо часу для їх завершення та перевірки роботи аудіо й відеосистеми.

Якщо в меню **Пуск** під час завершення роботи з’являється пункт **Оновити й завершити роботу** або **Оновити й перезавантажити**, це означає, що Windows підготувала оновлення, для завершення встановлення яких потрібна відповідна дія.

### Енергоживлення

Налаштуйте живлення так, щоб комп’ютер не переходив у режим сну під час запланованої роботи аудіо та відеосистеми.

1. Відкрийте **Пуск → Параметри → Система → Живлення та акумулятор** або відповідний розділ **Живлення**.
2. Знайдіть параметри вимкнення екрана та переходу в режим сну.
3. Вимкніть режим сну обрав варіант "Ніколи".

## 15. Перевірка роботи та усунення проблем

### Підсумкова перевірка

- [ ] Windows 11 встановлено й активовано.
- [ ] Установлено потрібні оновлення.
- [ ] У Диспетчері пристроїв немає невирішених проблем із драйверами.
- [ ] Microsoft Defender або затверджене рішення захисту працює.
- [ ] Облікові записи створено.
- [ ] Правильно налаштовано дату, час і часовий пояс.
- [ ] Всі дисплеї працюють у потрібному режимі.
- [ ] JW Library запускається й відтворює потрібні матеріали.
- [ ] VLC запускається й відтворює потрібні медіафайли.
- [ ] Перевірено звук через фактичну аудіосистему.
- [ ] Комп’ютер не переходить у режим сну під час потрібної роботи.
- [ ] Інсталяційну флешку безпечно витягнуто та збережено для подальшого використання.

### Типові проблеми

**Комп’ютер не завантажується з флешки**

- Перевірте, чи правильно створено інсталяційний носій.
- Спробуйте інший USB-порт.
- Відкрийте меню завантаження та виберіть USB-пристрій із позначенням UEFI.
- За потреби перевірте документацію виробника.

**Інсталятор не бачить диск**

- Перевірте, чи визначається накопичувач у BIOS/UEFI.
- На деяких комп’ютерах може знадобитися драйвер контролера накопичувача.
- Не змінюйте параметри контролера зберігання навмання, особливо якщо на комп’ютері є інші системи або важливі дані.

**Windows не активується**

- Перевірте підключення до Інтернету.
- Переконайтеся, що встановлено правильну редакцію Windows.
- Перевірте ліцензію або зверніться до відповідального брата.

**Не працює один із дисплеїв**

- Перевірте живлення дисплея та кабель.
- Відкрийте параметри дисплея й натисніть «Визначити».
- Перевірте драйвер відеокарти та правильність вибраного входу на дисплеї.

**Немає звуку**

- Перевірте гучність і вимкнення звуку.
- Переконайтеся, що вибрано правильний пристрій виведення.
- Перевірте підключення до аудіосистеми та драйвер аудіопристрою.

**JW Library або VLC не відтворює файл**

- Видаліть і перезаванажьте файл.
- Перезавантажьте комп'тер.
- Видаліть і перезаванажьте JW Library.

Якщо проблему не вдалося вирішити, зафіксуйте повідомлення про помилку та зверніться до відповідального за технічне обслуговування. Не намагайтеся виправити її випадковими змінами системних налаштувань.
