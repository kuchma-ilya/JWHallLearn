# JWHallLearn

### Посібник із налаштування та обслуговування комп'ютера Залу Царства

Цей репозиторій містить інструкції для встановлення, налаштування та обслуговування комп'ютера, який використовується для роботи аудіо та відеосистеми.

---

## Зміст

### 🪟 1. Операційна система

Інструкції зі встановлення та початкового налаштування Windows.

- **[Встановлення Windows 11](./Windows/WinInstall.md)**  
  Встановлення операційної системи та початкове налаштування комп'ютера.

- **[Драйвери](./Windows/Drivers.md)**  
  Встановлення, оновлення та перевірка драйверів обладнання.

### 2. BIOS / UEFI

Налаштування параметрів материнської плати та запуску комп'ютера.

- **[Налаштування BIOS / UEFI](./BIOS/BIOSet.md)**  
  Параметри завантаження, живлення та інші важливі налаштування.

## 🚀 Рекомендований порядок налаштування

1. Встановити Windows 11.
2. Виконати початкове налаштування операційної системи.
3. Встановити необхідні драйвери.
4. Перевірити параметри безпеки та оновлення.
5. Завантажити всі необхідні программи.
6. Налаштувати аудіо та відеообладнання.
7. Провести фінальну перевірку працездатності системи.
8. Перевірити налаштування BIOS / UEFI.

---

## Загальні рекомендації

- Перед зміною налаштувань створюйте резервні копії важливих даних.
- Перевіряйте сумісність драйверів з обладнанням та версією Windows.
- Змінюйте параметри BIOS / UEFI лише тоді, коли розумієте їх призначення.
- Після завершення налаштування перевіряйте роботу всіх компонентів системи.
- Документуйте важливі зміни, щоб полегшити подальше обслуговування.
